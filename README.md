# BiLivex - 哔哩哔哩直播间增强插件（油猴 Tampermonkey）

参考斗鱼 douyuex 插件交互，适配 B 站直播间（live.bilibili.com）的油猴增强脚本。

## 安装

- **Greasy Fork（推荐）**：https://greasyfork.org/zh-CN/scripts/590601
- 或直接在 Greasy Fork 搜索「BiLivex」安装

## 功能

| 功能 | 说明 |
|------|------|
| **弹幕悬停 +1** | 鼠标悬停聊天区弹幕 → 弹幕高亮（B站蓝底色）+ 右侧出现「+1」按钮 → 点击自动填入并发送同内容弹幕 |
| **弹幕复制** | 悬停弹幕时出现「复制」按钮，一键复制弹幕文本 |
| **弹幕小尾巴** | 发送弹幕（+1 或自行输入）时自动在末尾附加预设文本（如「你好」→「你好喵」）；独立小窗口可开关 + 编辑文本 |
| **屏蔽关键词** | 隐藏含关键词的弹幕，关键词逗号分隔，可开关 |
| **一键点赞 30 连击** | 一键连续点赞 30 次，用于激活 B 站粉丝团灯牌；按钮旁小字提示「点一次 = 连续点赞 30 次，可点亮粉丝团灯牌」，点赞期间自动防重复 |
| **漂浮弹幕悬停 +1** | 直播画面上漂浮经过的弹幕，鼠标悬停自动冻结并浮现「+1」按钮，点击发送同内容弹幕；点击后弹出「✓ +1」动画反馈；与右侧聊天区 +1 共用发送链路 |
| **主题切换** | 面板顶部切换「蓝色」（B站蓝 #00AEEC）或「粉色」（B站粉 #FB7299）主题，设置持久化；粉色主题下 30 连击按钮自动改为蓝系互补色，整体协调统一 |
| **侧边悬浮主菜单** | B 站蓝/粉主题悬浮面板，置于直播间右侧，可折叠、可拖拽，所有设置持久化 |

## 手动安装

1. 浏览器安装 Tampermonkey（油猴）扩展
2. 打开油猴管理面板 → 新建脚本 → 删除模板内容 → 粘贴 `bilive-enhance.user.js` 全部内容 → 保存
   （或直接双击 `.user.js` 文件，油猴会弹出安装页）
3. 打开任意 B 站直播间（live.bilibili.com/房间号），右侧出现 BiLivex 面板即生效

## 使用说明

- **+1 / 复制**：鼠标悬停到聊天区某条弹幕上，弹幕右侧浮现操作按钮
- **小尾巴设置**：面板中「小尾巴」开关 + 「尾巴内容」输入框（默认"喵"）
- **持久化**：设置自动保存（GM_setValue/GM_getValue），刷新/换房不丢失
