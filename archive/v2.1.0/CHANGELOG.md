# 更新日志

## v2.1.0（2026-09-06）

新功能与改进：
1. 参考 [DouyuEx](https://greasyfork.org/zh-CN/scripts/394497-douyuex-%E6%96%97%E9%B1%BC%E7%9B%B4%E6%92%AD%E9%97%B4%E5%A2%9E%E5%BC%BA%E6%8F%92%E4%BB%B6) 的「同步时间」思路，在 B 站播放器底部原生操作栏的直播持续时间右侧新增同步按钮，并按 B 站播放器结构独立适配。
2. 点击后优先跳到最后一段本地缓冲区末端前 0.05 秒；缓冲区不可用时回退到播放器可拖动区间末端，避免卡在 MSE 分段边界。
3. 同步操作只调整 `video.currentTime`，不会主动调用播放或暂停，也不会点击、替换或拦截 B 站任何原生控件。
4. 按钮跟随相邻原生图标样式，并支持控制栏延迟挂载、卸载重建、切换直播间和特殊直播间；重复初始化只保留一个按钮。
5. 根据实机反馈重绘同步图标：外圈以 24 × 24 视区中心对称，箭头移至左上角，缩短中心时针并减细描边，避免箭头与时针挤在一起。
6. 新增目标区间单元测试，以及按钮位置、图标几何、原生视觉、同步行为、原生控件隔离和控制栏重建等浏览器测试。
