# BiLivex 🎮

**B站直播间增强工具：六分类悬浮窗、带弹幕画中画、仅音频模式、直播间净化、特别关注开播提醒、独轮车、弹幕 +1、收藏夹、小尾巴、一键点赞、同步时间及可选观看设置。开源地址：https://github.com/eeeachan27/BiLivex**

## 📢 升级提示

当前正式版本为 **3.1.0**。升级已有脚本时，请在原 BiLivex 脚本中更新；已有收藏、关注名单和偏好继续沿用。

主面板改为“常用、观看、弹幕、收藏、关注、设置”六分类，提供功能搜索和最多四项常用入口。悬浮球及标题栏使用正式 Logo，展开收起、长短菜单和导航下划线平滑过渡；系统开启“减少动态效果”时关闭动效。

收藏、关注和常用入口的未保存修改保留在当前页面会话中，切分类、搜索和收起不会直接丢弃；点击各自保存按钮才提交，刷新页面不保留未保存草稿。独轮车暂停或聊天页面离开时及时取消排队和待发操作，保留用户新草稿与组合输入。

本文及界面统一称直播画面上飘过的内容为“弹幕”，右侧评论区的内容为“评论”。画面悬停入口称为“弹幕操作”，评论菜单中的同内容发送按钮称为“评论+1”。

### 3.1.0：画中画与仅音频

3.1.0 新增两种手动开启的观看模式。带弹幕画中画需要浏览器支持 Document Picture-in-Picture；仅音频需要当前直播提供可用的独立音频流。播放器或直播间变化时会退出模式，回原页确认画面后可重新开启。

- **观看 → 带弹幕画中画**：在支持 Document Picture-in-Picture 的浏览器中打开置顶小窗，优先捕获原视频画面；捕获受限时可手动选择搬移原视频。小窗显示独立弹幕，可调音量和暂停，通过右上角原生返回图标返回直播间。增强模式期间原页呈黑屏提示，底栏保持可用；点击原页“返回直播间”或关闭小窗恢复画面，声音及小窗播放继续。小窗底栏随鼠标进入内容区显示、离开后淡出，Tab 操作时保持可见，显隐不挤压画面。提示展示 5 秒，右侧“×”可手动关闭；浏览器自带的窗口关闭按钮仍保留。“弹幕操作”开启时，悬停弹幕显示 +1 / 收藏，操作按钮支持键盘；不再提供“选择可见弹幕”入口。弹幕操作栏避让底栏和提示，遮挡部分不参与命中。暂不继承原生屏蔽词，显隐由小窗按钮控制。普通画中画入口明确不含弹幕与操作栏。
- +1 继续使用当前房间原生控件，保留草稿、组合输入和共享发送顺序。请求中按钮不可重复激活；关闭小窗、换房或关闭弹幕操作时取消尚未触发的请求，结果未确认不自动重发。收藏沿用原库与来源房间。
- **观看 → 仅音频模式**：准备可用的独立音频流后停止原生视频加载，保留音量与静音；暂停音频时停止其加载，恢复后重新连接当前直播。点击“恢复视频”返回原生播放，可能出现短暂加载间隙。接口、媒体或播放器不支持时保留/尝试恢复视频并给出原因。
- **播放器底部栏**：同步时间保持在原时间显示右侧；“仅音频模式”位于原生音量调节右侧；“增强画中画”位于原生画中画按钮右侧。支持 Tab、Enter/空格；音频期间同步不可用，独立音频区提供恢复视频。原生画中画锚点未知时保留观看分类入口，不猜测位置。
- 两种模式默认不运行，每页手动开启，不随刷新或换房自动重启；仅音频从页面缓存返回时恢复原生视频，保留音量、静音和暂停意图，不自动重启仅音频；切换前先退出当前模式。已有全屏或其他画中画时先退出；运行中切换网页模式或进入全屏会结束本功能。生效期间自动最高画质和网页模式保留偏好、暂不执行；仅音频期间视频同步不可用。修改 P2P 设置先退出媒体模式，再按原路径重载。
- 首次启用仅音频会按需加载固定音频播放器资源；网络访问失败会退出并尝试恢复视频。弹幕连接信息过期时需要刷新原页。仅在实际支持的浏览器、房间及页面布局中启用。

### 净化与新版入口

- **观看 → 直播间净化 → 页面区域**：可分别隐藏已适配的礼物栏、排行榜入口和活动入口，默认关闭。它只改变显示，不节省网络流量。
- **观看 → 直播间净化 → 聊天提示**：可隐藏已适配的原生礼物行和聊天框上方的礼物气泡，包括粉丝团灯牌；普通、回复、表情、本人和付费消息保持可见。“隐藏进场提示”覆盖下方专用进场条和上方专用进场画布（包括舰长进场动画）；下方进场条可安全收拢占位，关闭后恢复原生尺寸，未知、关注及分享提示保留。
- 五个开关独立保存，沿用原偏好。“恢复原样”会关闭全部五项净化；如果某项写入或回读失败，本页先恢复显示并暂停该项，提示失败。主动开启可重试，刷新后可能重新应用原保存值。
- 原“聊天净化”入口合并到“直播间净化”。搜索“聊天净化”“进场”“灯牌”“礼物提示”等词均可定位统一入口；旧常用入口自动映射并保序去重，浏览时不覆盖原配置，显式保存后写入统一标识。
- **设置 → 常用入口配置**：调整常用入口顺序、清空或恢复默认，最多四项；导航和搜索只打开功能，不直接发送或点赞。编辑期间被其他页面改为未知配置格式时拒绝覆盖，保留草稿。
- **设置 → 外观主题 / 恢复窗口位置 / 版本与更新**：集中管理外观和版本。独轮车仍有原发送栏入口；运行时主面板提供任务状态和暂停入口。

净化按已适配的原生结构判断，未识别区域保持原样；适配情况随站点布局变化。进场与礼物提示独立运行，关闭或异常时恢复显示。活动直播页的同源子页面重载及全屏切换后，面板继续保持分类、输入和未保存草稿。

### 开播提醒使用

1. 在 `live.bilibili.com` 登录后打开 BiLivex 主菜单，在“关注”分类点击“管理特别关注”，首次打开会读取关注列表。列表显示头像、昵称和 UID；当前直播间置顶，其余按粉丝团灯牌等级从高到低排列，无灯牌的按名称排列。可搜索、全选全部、全选搜索结果或清空选择；入口按钮颜色随主菜单主题变化。
2. 保存名单，在“关注 → 开播提醒”中开启开关。新选择和首次启用会先静默记录当前直播状态，以后检测到新场次才提示。
3. 提醒只在打开的 B 站 HTTPS 页面显示，第三方网站不显示；没有打开的 B 站页面时无法监测。提示的“我知道了”带 5 秒倒计时，“火速前往”在新标签页打开直播间。
4. 关注列表和灯牌等级由 B 站只读接口提供。如果接口受限或名单不完整，旧选择会保留；灯牌等级暂不可用时列表按名称排列，可稍后手动刷新。账号切换后需要返回直播页核对身份。

### 独轮车使用

1. 点击原生“发送”按钮左侧的轮椅图标，打开独立小窗口。拖动标题栏可以移动窗口，右上角可收起；收起不等于停止。
2. 选择“文字”，在每个单行文本框中填写一条内容，也可展开“从收藏夹添加”快速加入收藏弹幕；设置发送间隔和自动停止秒数。0 表示不限时。预览会自动计算小尾巴与长文本切分。
3. 选择“表情”后，按原生表情包分组浏览。点击带封面的标题可展开或折叠；折叠后仍显示封面、表情数量和已选数量。点选多个表情可按顺序循环，选择按房间分别保存。
4. 检查内容后点击“开始”，同一个按钮变为“暂停”；点击“暂停”立即停止当前任务并恢复为“开始”。文字和表情首条立即发送。

间隔最少 5 秒。随机间隔、单条长度、返回房间后自动恢复位于“更多发送选项”。恢复默认关闭，启用后有 3 秒可取消倒计时。用户正在输入时自动等待，不覆盖草稿；结果不明确时不会马上重发，连续两次未确认会停止。

收藏库升级为版本 2，保留原条目并在首次写入前备份旧存储。“仅当前直播间”按来源筛选，旧收藏的未知来源不会被猜测分配。收藏夹中的“车”按钮和独轮车内的收藏选择器共用稳定收藏 ID。导入支持版本 1 和版本 2，确认预览后才提交。跨标签保存使用浏览器 Web Locks；不可用或版本冲突时拒绝覆盖，并保留草稿。

表情车参考 BLSPAM 的“按房间保存选择、按选择顺序循环”逻辑，但继续使用 B 站原生表情面板和发送控件，不读取 Cookie，也不直接调用弹幕发送接口。普通表情经原生输入框发送，房间专属表情点击原生表情项；未解锁或当前房间不可用的表情不会启动。状态中的“已确认”指观测到原生输入框清空或评论区出现新的本人评论，不代表服务器回执。

## ✨ 核心功能

| 功能             | 说明                                                               |
| -------------- | ---------------------------------------------------------------- |
| **特别关注开播提醒** | 从已关注主播中选择提醒对象；开播后在打开的 B 站页面显示 5 秒软提示，可直接进入直播间，默认关闭 |
| **独轮车** | 多条文字与收藏序列、长文本完整切分、当前房间表情循环、固定或随机间隔与自动停止；保护用户输入，换房停车，同房间仅允许一个标签页运行 |
| **评论区快捷操作** | 点击右侧评论区的一条评论，在 B 站原生菜单末尾使用「评论+1 / 复制 / 收藏」；操作后菜单自动关闭，成功提示显示在鼠标附近 |
| **弹幕操作** | 鼠标悬停直播画面内实际可见的弹幕部分，弹幕按画面边界高亮并出现「+1／收藏」操作栏，通过 B 站原生控件发送同内容弹幕 |
| **弹幕小尾巴**      | 发送弹幕（+1 或自行输入）时自动在末尾附加预设文本（如「你好」→「你好喵」）；独立小窗口可开关 + 编辑文本          |
| **一键点赞 30 连击** | 一键连续点赞 30 次，点亮 B 站粉丝团灯牌                                          |
| **同步时间**       | 播放器底栏直播持续时间右侧显示原生风格按钮，一键跳到最后一段缓冲区的最新位置，不改变原有播放 / 暂停状态 |
| **直播间净化** | 独立隐藏礼物栏、排行榜入口、活动入口、进场提示和礼物提示；默认关闭，可恢复原样 |
| **观看设置**       | 可选自动最高画质、自动网页模式和防止 P2P 上传，三个开关默认关闭，可按需启用 |
| **主题切换**       | 在“设置 → 外观主题”切换「B 站蓝」/「B 站粉」主题，配色联动全局（标题 / 开关 / 按钮 / 弹幕高亮 / 反馈动画），设置持久化 |
| **侧边悬浮主菜单**    | 蓝 / 粉主题悬浮面板，置于直播间右侧，可折叠、可拖拽，六分类与搜索，最多四项常用入口                             |
| **弹幕收藏夹**        | 收藏常用弹幕，支持搜索、编辑、删除、导入导出，并可一键填入、发送或加入独轮车序列                         |
| **自动检查更新**      | 周期检测新版本，发现更新时在悬浮球旁弹出提示，可一键打开油猴更新页升级                |

## 🎯 使用说明

- **评论区快捷操作**：点击右侧评论区某条评论，在 B 站原生菜单末尾选择「评论+1」「复制」或「收藏」；三项始终可用，不受“弹幕操作”开关影响
- **弹幕操作**：在“弹幕 → 弹幕操作”中开启画面悬停入口。鼠标悬停直播画面内实际可见的弹幕部分即可冻结；未完全进入画面的内容和高亮框保持裁剪，操作栏改在左侧展开。此开关只控制画面内的弹幕操作
- **小尾巴设置**：面板中「小尾巴」开关 + 「尾巴内容」输入框（默认「喵」）
- **自己的弹幕**：保留 B 站原生本人弹幕标识，不额外伪造样式
- **同步时间**：鼠标移入直播画面唤出底部操作栏，点击直播持续时间右侧的圆形箭头按钮，即可追到当前缓冲区的最新画面
- **主题设置**：在“设置 → 外观主题”切换蓝色 / 粉色主题，偏好自动保存
- **持久化**：开关与外观即时保存；收藏、关注和常用编辑需点击保存。未保存草稿仅保留于当前页面会话
- **弹幕收藏夹**：点击面板中的「收藏」打开收藏夹；支持关键词搜索、编辑、删除、导入导出。点击收藏文本可填入聊天框，点击「+1」可发送同内容弹幕，点击「车」可加入文字独轮车序列。填入或 +1 前需要先处理聊天框已有草稿并完成输入法组合；等待期间出现新输入时保留内容并停止发送。页面离开或换房会取消旧请求，返回后需重新操作。
- **开播提醒**：在直播页主菜单管理特别关注名单并开启开关；提示可在 B 站主站及直播页等 B 站网页显示，站外不运行。关闭 B 站页面或浏览器后无法继续监测。
- **自动检查更新**：每 1 小时自动检测一次新版本，发现更新时在悬浮球旁弹出提示；点击「忽略」不再提示该版本，点击「更新」在新标签页打开油猴更新页完成升级
