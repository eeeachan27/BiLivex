# 更新日志

## v2.2.0（2026-09-07）

新功能与改进：
1. 在“更多设置”中新增自动最高画质、自动网页模式和防止 P2P 上传三个可选开关，默认关闭。
2. 自动最高画质会根据当前直播间可用画质选择最高档位，并在播放器稳定后执行，避免首屏加载圈残留。
3. 自动网页模式会在进入直播间和播放器重建后自动进入网页模式，兼容普通直播间与活动页播放器。
4. 防止 P2P 上传使用 B 站原生参数和播放器重载路径，不改写 WebRTC 或网络全局接口；切换房间时会重新校验状态。
5. 优化慢网、播放器换流、播放器重建和多个 iframe 同时存在时的状态隔离，避免重复调用和旧任务覆盖新状态。
6. 延续 2.1.0 的同步时间功能，并补充自动化回归测试，覆盖普通直播间、活动页、控制栏重建和 SPA 换房场景。
